Step 06 · Beginner · Compute, data, networking, identity, and operations on Google Cloud

Google Cloud core services

Google Cloud is strong in containers, data and analytics, and global networking. This step covers the core services and the project and organisation model.

Cloud RunGKEBigQueryVPC and IAMPub/SubOperations

1. Resource hierarchy

Resources belong to projects, which sit in folders under an organization. IAM and Organization Policy inherit down the hierarchy. Use projects as boundaries per workload and environment, and Shared VPC to centralise networking.

4. Networking

  • VPC networks are global; subnets are regional. Firewall rules and hierarchical firewall policies control traffic.
  • Private Service Connect and Private Google Access keep traffic private; VPC Service Controls create data-exfiltration perimeters.
  • Global external Application Load Balancer with Cloud CDN and Cloud Armor; Cloud DNS; Cloud NAT.
  • Hybrid: Cloud VPN, Cloud Interconnect, Network Connectivity Center.

5. Identity and security

  • IAM binds principals to roles at a resource scope; prefer predefined or custom roles over basic Owner/Editor.
  • Service accounts for workloads: avoid downloaded keys; use attached service accounts and Workload Identity Federation for external systems.
  • Organization Policy constraints, Cloud KMS, Secret Manager, Security Command Center, Cloud Audit Logs.
  • Identity-Aware Proxy provides zero-trust access to apps.
