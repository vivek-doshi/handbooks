Step 04 · Beginner · Compute, data, networking, identity, and operations on Azure

Azure core services

Azure is strongest where enterprises already use Microsoft identity and tooling. This step covers the services you will use most and the resource model that organises them.

App Service and FunctionsAKS and Container AppsStorage and dataVNet and Entra IDMonitorCost

1. The resource model

Resources live in resource groups inside subscriptions, organised under management groups and a Microsoft Entra tenant. Policy and RBAC assigned at a higher scope inherit downward. Use subscriptions as boundaries for environments, workloads and billing.

4. Networking

  • VNets and subnets with NSGs; hub-and-spoke or Virtual WAN for scale; Azure Firewall for central egress control.
  • Private Link and private endpoints keep PaaS traffic off the internet.
  • Entry: Front Door (global, with WAF), Application Gateway (regional L7), Load Balancer (L4), Traffic Manager, DNS.
  • Hybrid: ExpressRoute and VPN Gateway.
  • Use Network Watcher and effective security rules to troubleshoot.

5. Identity and security

  • Microsoft Entra ID for users and workloads: use managed identities instead of secrets, Conditional Access, MFA and Privileged Identity Management for just-in-time admin access.
  • Azure RBAC assigns roles at a scope; Azure Policy enforces rules and compliance.
  • Key Vault for keys, secrets and certificates; Microsoft Defender for Cloud for posture and threat protection; Microsoft Sentinel as SIEM.
