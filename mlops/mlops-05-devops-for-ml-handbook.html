DevOps for ML: CI/CD/CT

If you know DevOps, this is the bridge. The tooling is familiar; what changes is what you test and what artifacts move through the pipeline.

def test_no_slice_regression(model, champion, slices):
    for name, d in slices.items():
        assert f1(model, d) >= f1(champion, d) - 0.01, name

A CI and CD pipeline

# .github/workflows/ci.yml (sketch)
on: [pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: {python-version: "3.11"}
      - run: pip install -r requirements.lock && pytest tests/unit tests/data
      - run: dvc pull data/sample && python -m pipelines.smoke   # tiny end-to-end run
      - run: docker build -f Dockerfile.serve -t model-serve:${{ github.sha }} .
      - run: trivy image --exit-code 1 --severity HIGH,CRITICAL model-serve:${{ github.sha }}

Use CML or workflow comments to post metric diffs on the pull request. Training on full data runs in the orchestrator, not in CI runners.

Containers, supply chain and security

  • Pin dependencies with lock files and use slim, scanned base images; separate train and serve images.
  • Sign images and models (Sigstore cosign, model signing) and generate SBOMs; scan for unsafe pickle files and prefer safetensors.
  • Secrets in a vault or workload identity, never in notebooks.
  • Least-privilege access to training data; audit who can promote models.
  • Pull third-party models and datasets only from reviewed sources, and pin by hash.

Infrastructure and GitOps

  • Terraform or Pulumi for clusters, buckets, registries, GPU node pools and endpoints; Helm or Kustomize for in-cluster apps.
  • GitOps (Argo CD or Flux): a Git change to the model version or alias rolls out the new serving revision, with rollback by revert.
  • Cost controls: quotas, autoscaling to zero, spot capacity, TTL on dev clusters.

Practice

Practice
  1. Add a data test and a model-gate test to an existing project and fail the build on regression.
  2. Build and scan a serving image in CI.
