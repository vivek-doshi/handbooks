API gateway patterns

An API gateway is the governed edge for routing, identity verification, traffic policy, and telemetry. It shields internal microservices from public exposure, while centralizing cross-cutting policies without violating backend domain ownership.

2. Rate Limiting Algorithms and Distributed State

AlgorithmMechanicsProsCons
Token Bucket Tokens refill at a constant rate up to capacity \(B\). Each request consumes 1 token. Permits temporary burst traffic up to bucket size; memory-efficient. Requires synchronized state in distributed clusters.
Leaky Bucket Requests enter a queue and leak out at a constant, fixed rate. Completely smooths egress traffic; shields fragile legacy backends. Adds latency to requests waiting in queue; drops traffic when queue is full.
Sliding Window Counter Calculates rolling weighted average from current and previous 60-second windows. Eliminates boundary burst attacks common to Fixed Windows. Requires atomic multi-key read/writes in Redis.

Distributed Token Bucket: Redis Lua Script

-- Redis Lua script for atomic distributed Token Bucket
local key = KEYS[1]
local limit = tonumber(ARGV[1])
local rate = tonumber(ARGV[2]) -- tokens added per millisecond
local now = tonumber(ARGV[3])

local data = redis.call('HMGET', key, 'tokens', 'last_updated')
local tokens = tonumber(data[1])
local last_updated = tonumber(data[2])

if tokens == nil then
  tokens = limit
  last_updated = now
else
  local elapsed = now - last_updated
  tokens = math.min(limit, tokens + elapsed * rate)
  last_updated = now
end

if tokens >= 1 then
  tokens = tokens - 1
  redis.call('HMSET', key, 'tokens', tokens, 'last_updated', last_updated)
  redis.call('EXPIRE', key, 60)
  return 1 -- ACCEPT REQUEST
else
  return 0 -- REJECT HTTP 429
end

3. Advanced Traffic Management: Canary and Blue-Green

Modern gateways route traffic dynamically without redeploying backend infrastructure:

  • Canary Deployments: Route 95% of traffic to v1-stable and 5% to v2-canary. If error rates or latency on v2 spike, the gateway automatically rolls back to 100% v1 in seconds.
  • Traffic Shadowing / Mirroring: Duplicate 100% of incoming live production traffic and send an asynchronous copy to a new version without awaiting its response. Tests real-world load and memory consumption with zero customer risk.
  • Header-Based Testing: Route requests containing internal QA headers (e.g., X-Beta-Tester: true) to experimental staging pods.

4. The Emerging AI Gateway Pattern

As enterprises adopt Large Language Models (OpenAI, Anthropic, Gemini, local Ollama), routing raw client requests directly to AI providers causes cost explosions, credential sprawl, and security vulnerabilities. An AI Gateway sits between enterprise applications and model providers.

Key AI Gateway Capabilities

  • Credential Isolation: Developers authenticate to internal services; the AI Gateway injects provider API keys securely from Vault.
  • Token-Aware Rate Limiting & Budgets: Enforces cost quotas by tracking prompt and completion tokens per department/tenant.
  • Multi-Model Fallback Routing: If OpenAI returns HTTP 429 (Rate Limit) or 503 (Outage), the gateway seamlessly routes the prompt to an equivalent Claude or Gemini endpoint.
  • Semantic Caching: Uses vector similarity (Redis / pgvector) to check if an identical or semantically identical prompt was answered recently. Returns cached responses instantly in 5 ms at $0 cost!
  • Prompt Injection & PII Guardrails: Scans incoming prompts and outgoing completions for credit cards, SSNs, and prompt injection payloads before forwarding.

5. Practical Exercises

  1. Gateway Selection: Your company is migrating 40 microservices to Amazon EKS and needs gRPC routing, OAuth JWT validation, and automated canary deployments. Evaluate Envoy Gateway vs. AWS API Gateway vs. Kong. Which best fits this topology?
  2. Rate Limit Design: Formulate a 3-tier rate limiting policy for a financial market data API (Free Tier: 10 req/min; Pro Tier: 1,000 req/min; Enterprise Tier: 10,000 req/min with dedicated burst allowances). Define standard IETF RateLimit-* HTTP response headers.
  3. AI Gateway Routing Rule: Design a configuration rule for an AI gateway that routes code generation prompts to Claude Sonnet, falls back to GPT-4o on timeout > 3s, and blocks any request containing unencrypted credit card regexes.
