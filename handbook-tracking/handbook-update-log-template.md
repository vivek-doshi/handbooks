# Handbook Update Log Template

Use this template when a handbook is updated.

## Entry

- Date: YYYY-MM-DD
- Handbook: path/to/handbook.html
- Owner: @team-or-user
- Change Type: content refresh | bug fix | style update | source link refresh | major rewrite
- Summary: One to three lines of what changed.
- Why: Reason for this update (new release, deprecation, correction, policy change).
- Source Links:
  - https://example.com/source-1
  - https://example.com/source-2
- Validation:
  - [ ] Handbook page reviewed in browser
  - [ ] Theme toggle and floating controls verified
  - [ ] handbook-version and last-updated metadata aligned
  - [ ] index.html link and card still valid
- Next Review Due: YYYY-MM-DD

## Notes

- Keep one log entry per handbook update.
- Add the final entry to your PR description or release notes.
