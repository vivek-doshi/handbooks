# Terminology

Use these terms consistently in docs, templates, and reviews for this repository.

## Canonical Terms

- Handbook: A standalone topic page with skimmable reference content.
- Index: The catalog page that links to all handbooks.
- Card: The visual entry on `index.html` that opens a handbook.
- Shared controls: The floating back button and theme toggle used across handbook pages.
- Shared assets: The common CSS and JS files under `styles/` and `scripts/`.
- Current context: The curated `.ai/` files that describe the repo as it exists now.
- Update flow: Add the page, add the index card, update the count, then refresh README and `.ai`.

## Preferred Wording

Use:

- concise handbook
- reusable shared UI
- explicit link to the source or companion page
- current repo context
- consistent theme behavior

Avoid:

- stale guidance
- duplicate page behavior
- hidden navigation controls
- unclear handbook ownership
