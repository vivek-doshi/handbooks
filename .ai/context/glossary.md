# Glossary

- Handbook: A short, topic-focused HTML reference page in this repo.
- Handbook card: The index entry that links to a handbook page.
- Shared UI: The common floating back button, theme toggle, and supporting styles/scripts.
- Floating actions: The fixed controls used to navigate back to the index and switch themes.
- Theme toggle: The shared control that switches between light and dark handbook themes.
- Index total: The number shown on `index.html` that should match the handbook cards rendered there.
- README context: The root-level summary used to orient contributors and Copilot.
- .ai context: Curated repository guidance files used by Copilot during edits.
- DevOps Playbook link: The external source referenced from `devops/devops-playbook-handbook.html`.
