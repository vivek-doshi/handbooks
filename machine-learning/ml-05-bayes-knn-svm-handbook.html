Step 05 · Beginner · Three classic algorithms built on probability, similarity and margins

Naive Bayes, k-nearest neighbours and support vector machines

These three classic algorithms each rest on a different idea: probability (Naive Bayes), similarity (KNN) and margins (SVM). Knowing how each thinks tells you when it is the right tool, and when it is not.

Naive BayesBayesian thinkingKNNSVMComparison

1. Naive Bayes

Naive Bayes classifier

  • What it does: Classifies a row by computing the probability of each class given its features, using Bayes theorem (step 02).
  • How it works: For each class it multiplies the class prior by the likelihood of every feature, assuming features are independent given the class (the "naive" part). That assumption is rarely true, yet predictions are often good. Training is just counting, so it is extremely fast.
  • Use it when: Text classification (spam, sentiment, topic), very small datasets, high-dimensional sparse data, a quick baseline, or when you need fast online updating.
  • Avoid it when: Features are strongly dependent and that matters, or you need well-calibrated probabilities (they tend to be extreme).
  • Key settings: alpha (smoothing so unseen words do not zero the probability); pick the variant by feature type, below.

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline

spam = make_pipeline(TfidfVectorizer(ngram_range=(1, 2), min_df=2), MultinomialNB(alpha=0.5))
spam.fit(train_texts, train_labels)
print(spam.predict(["Win a free prize now"]))

2. Bayesian thinking beyond Naive Bayes

"Bayesian" is a wider idea than the Naive Bayes classifier: treat unknowns as probability distributions, start from a prior, and update with data.

  • Uncertainty: Bayesian models return a distribution (a plausible range), not just a single guess. Valuable with small data and high-stakes decisions.
  • Priors as regularisation: ridge regression equals a Gaussian prior on weights, and lasso a Laplace prior. Regularisation is Bayesian thinking in disguise.
  • Tools: scikit-learn offers BayesianRidge and Gaussian processes; probabilistic programming libraries such as PyMC and NumPyro build full custom models.
  • Bayesian optimisation uses the same idea to choose hyperparameters efficiently (step 08).
  • A/B testing can use Bayesian methods to say "the probability that B is better is 94%".

3. k-nearest neighbours (KNN)

k-nearest neighbours

  • What it does: Predicts by looking at the k most similar training rows and taking the majority class (classification) or average (regression).
  • How it works: There is no training in the usual sense: it stores the data and, at prediction time, measures distance to every stored row (step 02). Closer neighbours can be weighted more.
  • Use it when: Small to medium datasets, a simple non-parametric baseline, recommendation-like similarity, and when the decision boundary is irregular.
  • Avoid it when: Large datasets (prediction is slow), many features (the curse of dimensionality makes all points look equally far), unscaled features, or noisy irrelevant features.
  • Key settings: n_neighbors (small k overfits, large k underfits; try odd values 3 to 25), weights (uniform or distance), metric (euclidean, manhattan, cosine).
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import GridSearchCV

pipe = make_pipeline(StandardScaler(), KNeighborsClassifier())
grid = GridSearchCV(pipe, {"kneighborsclassifier__n_neighbors": range(3, 26, 2),
                           "kneighborsclassifier__weights": ["uniform", "distance"]}, cv=5)
grid.fit(X_train, y_train)
print(grid.best_params_, grid.best_score_)
Scale first, alwaysKNN compares raw distances, so a feature measured in thousands drowns out one measured in fractions. Standardise before fitting. For millions of rows or embeddings, use approximate nearest-neighbour search (see the vector database handbook), which is KNN at scale.

4. Support vector machines (SVM)

Support vector machine

  • What it does: Finds the decision boundary that separates classes with the widest possible margin; only the few rows closest to the boundary (the support vectors) matter.
  • How it works: Maximises the margin while allowing some mistakes, controlled by C. With a kernel it works in a richer implicit feature space, so it can draw curved boundaries without you building the features.
  • Use it when: Small to medium datasets (up to tens of thousands of rows), high-dimensional data such as text or genomics, and clean problems where the classes are separable with a margin.
  • Avoid it when: Very large datasets (training is slow and memory-heavy), heavy noise and overlapping classes, or when you need probabilities and interpretability.
  • Key settings: C (large = fit training data tightly, small = wider margin), kernel (linear, rbf, poly), gamma (how far one point's influence reaches for rbf; large = wiggly boundary).
from sklearn.svm import SVC, LinearSVC, SVR
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rbf = make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0, gamma="scale", probability=True))
fast_linear = make_pipeline(StandardScaler(), LinearSVC(C=1.0))     # use for large or text data
rbf.fit(X_train, y_train)
  • Kernels: linear for high-dimensional sparse data; RBF is the sensible default for general problems.
  • Scaling is mandatory. Tune C and gamma together on a log scale (for example 0.01 to 100).
  • Regression: SVR fits a tube around the data and ignores errors inside it (epsilon).
  • Probabilities: probability=True adds an internal cross-validation and slows training; consider calibration instead (step 08).

In practice, once you reach tabular data of moderate size, gradient boosting (step 06) usually beats all three. These algorithms remain useful for text, small data, quick baselines and for teaching how different assumptions shape a model.

Practice
  1. Build a spam or sentiment classifier with TF-IDF and MultinomialNB, then try LinearSVC and logistic regression on the same features.
  2. Fit KNN with and without scaling and compare scores.
  3. Plot SVM decision boundaries for gamma = 0.01, 1 and 100 on a two-feature toy dataset to see underfitting and overfitting.
