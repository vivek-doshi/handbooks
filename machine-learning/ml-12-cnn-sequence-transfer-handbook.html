CNNs, sequence models and transfer learning

Different data needs different architectures. This step covers the families that dominated before transformers and still matter: CNNs for images, recurrent models for sequences, embeddings, and above all transfer learning, which is how most real projects start.

CNNsVision tasksSequence modelsEmbeddingsTransfer learningWhich architecture?

1. Convolutional neural networks (CNNs)

Images have local structure: nearby pixels relate, and a pattern is the same wherever it appears. A convolution slides a small learned filter over the image to detect an edge, texture or shape. Stacked layers detect increasingly complex patterns.

ConceptMeaning
Filter / kernelA small grid of learned weights (for example 3 x 3)
Feature mapThe filter's output across the image
Stride and paddingStep size of the filter; border handling that preserves size
PoolingDownsamples feature maps (max or average), adding small shift tolerance
Receptive fieldHow much of the input one unit can "see"; grows with depth
Parameter sharingThe same filter is reused everywhere, so far fewer weights than a dense layer
import torch.nn as nn

class SmallCNN(nn.Module):                      # for 28 x 28 grey images
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.BatchNorm2d(32), nn.ReLU(), nn.MaxPool2d(2),   # 14 x 14
            nn.Conv2d(32, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(), nn.MaxPool2d(2))  # 7 x 7
        self.head = nn.Sequential(nn.Flatten(), nn.Linear(64 * 7 * 7, 128), nn.ReLU(),
                                  nn.Dropout(0.3), nn.Linear(128, n_classes))
    def forward(self, x):
        return self.head(self.features(x))
  • Landmark architectures: ResNet (residual connections make very deep networks trainable), EfficientNet and ConvNeXt (efficient, modern CNN designs). Vision transformers (step 13) are now equally common.
  • Augmentation is essential: random crops, flips, rotations, colour jitter and normalisation using the pretrained model's statistics.
  • Always evaluate on images from the real deployment conditions (lighting, camera, population).

3. Sequence models: RNNs, LSTMs and GRUs

A recurrent neural network processes a sequence one step at a time, carrying a hidden state forward as memory. Plain RNNs struggle with long sequences because gradients vanish over many steps (step 10).

ModelHow it helpsNotes
LSTMGates control what to remember, forget and outputHandles longer dependencies; slower to train because it is sequential
GRUSimpler gated unit, fewer parametersOften matches LSTM
Bidirectional RNNReads the sequence both waysUse when the whole sequence is available
1D CNN / temporal CNNConvolutions over timeFast, parallel; strong for sensors and short-range patterns
class LSTMClassifier(nn.Module):
    def __init__(self, vocab, emb=128, hidden=128, n_classes=2):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb, padding_idx=0)
        self.lstm = nn.LSTM(emb, hidden, batch_first=True, bidirectional=True)
        self.fc = nn.Linear(2 * hidden, n_classes)
    def forward(self, tokens):                   # tokens: (batch, seq_len) of ids
        out, _ = self.lstm(self.emb(tokens))
        return self.fc(out.mean(dim=1))
Where things standTransformers (step 13) have replaced RNNs for language and most sequence tasks because they train in parallel and capture long-range context. LSTMs, GRUs and temporal CNNs remain practical for small time-series and on-device problems, and newer state-space models revisit recurrence for efficiency.

Time series is often best handled first with a seasonal baseline and gradient boosting on lag and calendar features (steps 06 and 09). Use deep models when you have many related series, long histories or exogenous signals. Validate with time-based splits only.

4. Embeddings and autoencoders

  • Embeddings map discrete items (words, products, users) to dense vectors where similar items are close. They can be learned inside your network (nn.Embedding) or taken from a pretrained model.
  • Use them for similarity search, recommendations, clustering and as compact features for other models (see the vector database handbook).
  • Autoencoders compress inputs through a bottleneck and reconstruct them. The compressed code is a learned, non-linear alternative to PCA; large reconstruction error flags anomalies (step 07).
  • Generative models (variational autoencoders, GANs and diffusion models) learn to create new samples; diffusion models underlie most current image generators.

5. Transfer learning and fine-tuning

Training a large network from scratch needs huge data and compute. Transfer learning starts from a model pretrained on a large dataset and adapts it to your task, so you get strong results with a few thousand examples. It is the default approach for images and text.

ApproachHowUse when
Feature extractionFreeze the pretrained network; train only a new output headVery little data, quick baseline
Partial fine-tuningUnfreeze the last blocks with a small learning rateModerate data; similar domain
Full fine-tuningTrain everything with a small learning ratePlenty of data; different domain
Parameter-efficient fine-tuning (LoRA)Train small adapter matrices onlyLarge models; limited GPU memory (see the fine-tuning handbooks)
import torch, torch.nn as nn
from torchvision import models

weights = models.ResNet18_Weights.DEFAULT
model = models.resnet18(weights=weights)
preprocess = weights.transforms()                 # the exact preprocessing the model expects

for p in model.parameters():
    p.requires_grad = False                       # freeze the backbone
model.fc = nn.Linear(model.fc.in_features, 5)     # new head for 5 classes
opt = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)

# Stage 2: unfreeze the last block with a much smaller learning rate
for p in model.layer4.parameters():
    p.requires_grad = True
opt = torch.optim.AdamW([
    {"params": model.layer4.parameters(), "lr": 1e-4},
    {"params": model.fc.parameters(), "lr": 1e-3}])
  • Use the pretrained model's own preprocessing and input size.
  • Hold out a validation set from your own domain; ImageNet accuracy is not your accuracy.
  • Hugging Face provides pretrained models for images, text and audio through one API (step 13); see the Hugging Face fine-tuning handbook.

Practice
  1. Fine-tune a pretrained ResNet on a small image dataset (your own photos or a public one) first as a frozen feature extractor, then with layer4 unfrozen. Compare validation accuracy.
  2. Train the SmallCNN from scratch on the same data. How much worse is it with few images?
  3. Train a bidirectional LSTM or 1D CNN on a sensor dataset and compare with gradient boosting on lag features.
