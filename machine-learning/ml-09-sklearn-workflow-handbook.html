The scikit-learn workflow and choosing an algorithm

This step ties steps 03 to 08 together. You will learn the scikit-learn pattern for leak-free end-to-end workflows, get a practical decision guide for picking an algorithm, and see four complete examples: churn, house prices, segmentation and text.

1. The estimator API

MethodPurposeApplies to
fit(X, y)Learn from dataAll estimators
predict(X)Predict labels or numbersModels
predict_proba(X)Class probabilitiesMost classifiers
transform(X)Apply a learned transformationScalers, encoders, PCA
fit_transform(X)Fit then transform (training data only)Transformers
score(X, y)Default metricModels
get_params / set_paramsRead and change hyperparametersAll; used by search

Because everything follows this contract, models are interchangeable, and any combination can sit inside a pipeline or a search.

2. Pipelines that cannot leak

A Pipeline chains preprocessing and a model into one estimator. Cross-validation then refits the preprocessing inside every fold, which removes preprocessing leakage by construction. Build the preprocessing once and reuse it for every candidate model.

from sklearn.compose import ColumnTransformer, make_column_selector as selector
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.model_selection import cross_val_score
import joblib

num = make_pipeline(SimpleImputer(strategy="median"), StandardScaler())
cat = make_pipeline(SimpleImputer(strategy="most_frequent"), OneHotEncoder(handle_unknown="ignore"))
pre = ColumnTransformer([("num", num, selector(dtype_include="number")),
                         ("cat", cat, selector(dtype_exclude="number"))])

candidates = {
    "logreg": make_pipeline(pre, LogisticRegression(max_iter=2000)),
    "hgb": HistGradientBoostingClassifier(categorical_features="from_dtype"),   # needs category dtype
}
for name, est in candidates.items():
    print(name, cross_val_score(est, X, y, cv=5, scoring="roc_auc").mean().round(3))

best = candidates["logreg"].fit(X, y)
joblib.dump(best, "model.joblib")      # only load files you created; joblib uses pickle
  • Persist the whole pipeline, not only the model, so production applies identical preprocessing.
  • Security: pickle-based files can run code on load. Never load a model file from an untrusted source; consider ONNX or skops for sharing.
  • Reproducibility: fix random_state, pin library versions, and log the data version with each run (see the MLOps handbook).

3. Algorithm chooser: when to use which

Start from the problem, then narrow by your data size and constraints. When unsure, run a baseline and one boosting model and compare with cross-validation.

5. Four end-to-end use cases

A. Customer churn (binary classification, imbalanced)

  1. Target: churned within 30 days; use a time-based split.
  2. Features: tenure, plan, usage trend, support tickets in the last 30 days (no post-churn fields).
  3. Baseline: majority class and last-month usage rule. Model: class-weighted logistic regression, then gradient boosting.
  4. Metric: PR-AUC and recall at the capacity of the retention team; choose the threshold from campaign cost versus customer value.

B. House price (regression)

from sklearn.compose import TransformedTargetRegressor
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.metrics import mean_absolute_error
import numpy as np

reg = TransformedTargetRegressor(HistGradientBoostingRegressor(), func=np.log1p, inverse_func=np.expm1)
reg.fit(X_train, y_train)               # model the log of price, predict in dollars
print(mean_absolute_error(y_test, reg.predict(X_test)))

Prices are right-skewed, so modelling the log of the target is a common improvement; report MAE in currency and compare with a per-neighbourhood median baseline.

C. Customer segmentation (unsupervised)

  1. Build recency, frequency and monetary-value features; log-transform and standardise.
  2. Run k-means for several k, check silhouette and stability, then profile each cluster in plain language.
  3. Validate with the business: can marketing act differently on each segment?

D. Text classification

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.metrics import classification_report

clf = make_pipeline(TfidfVectorizer(ngram_range=(1, 2), min_df=3, sublinear_tf=True),
                    LogisticRegression(C=4, max_iter=2000))
clf.fit(train_texts, train_labels)
print(classification_report(test_labels, clf.predict(test_texts)))

TF-IDF plus a linear model is a strong, cheap baseline. Move to a fine-tuned transformer (step 13) only if the baseline is not good enough.

6. What to do next

  • Practise on real datasets: Kaggle, UCI, or your own company data, always with a baseline and a proper split.
  • Move to neural networks and deep learning (steps 10 to 13) for images, audio, text and sequences.
  • Learn to ship models: MLOps, MLflow and the Kubeflow handbooks.
  • Plan for life after deployment: monitoring drift, retraining, and model governance (see the AI governance handbooks).
Practice
  1. Pick one dataset and solve it with a baseline, logistic regression, random forest and gradient boosting using the same pipeline and cross-validation. Write a short comparison.
  2. Save the winning pipeline with joblib and reload it in a fresh script to predict one new row.
