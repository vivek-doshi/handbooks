Step 07 · Intermediate · Clustering, dimensionality reduction and anomaly detection when there are no labels

Unsupervised learning

When there is no target to predict, unsupervised learning finds structure: groups of similar rows, a smaller set of features, or the rows that do not fit. This step covers the main algorithms and the honest way to judge results that have no answer key.

1. What unsupervised learning is for

GoalTechniquesExample
Group similar itemsK-means, hierarchical, DBSCAN or HDBSCAN, Gaussian mixtureCustomer segmentation, document grouping
Compress or visualise featuresPCA, t-SNE, UMAP, autoencodersPlot 100 features in 2D; remove noise
Find unusual rowsIsolation forest, local outlier factor, one-class SVMFraud, sensor faults, intrusion
Find co-occurring itemsAssociation rules (Apriori, FP-Growth)Market basket analysis
Scale first, and expect judgementDistance-based methods need standardised features. There is no accuracy score, so results must be validated with domain experts and by checking that groups are stable and useful.

2. K-means and hierarchical clustering

K-means

  • What it does: Partitions rows into k groups, each represented by its centre (centroid).
  • How it works: Pick k centres (k-means++ initialisation), assign each row to the nearest centre, move each centre to the mean of its rows, and repeat until stable.
  • Use it when: You expect compact, similar-sized, roughly round clusters and want a fast method that scales to large data: customer segments, colour quantisation, preprocessing.
  • Avoid it when: Clusters have odd shapes, very different sizes or densities, many outliers, or you do not know k and cannot inspect results.
  • Key settings: n_clusters (choose with silhouette score or the elbow method plus business sense), n_init, init="k-means++".
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X)
for k in range(2, 9):
    labels = KMeans(n_clusters=k, n_init=10, random_state=0).fit_predict(Xs)
    print(k, round(silhouette_score(Xs, labels), 3))

Hierarchical (agglomerative) clustering

  • What it does: Builds a tree of clusters by repeatedly merging the two closest groups.
  • How it works: Start with each row alone and merge using a linkage rule (ward for compact groups, average, complete, single). A dendrogram shows the merges so you can cut at any level.
  • Use it when: You want to see structure at several granularities, have a small dataset, or need clusters of arbitrary shape (single linkage).
  • Avoid it when: Datasets with tens of thousands of rows or more (memory grows quadratically).
  • Key settings: linkage, n_clusters or distance_threshold, metric.

3. DBSCAN, HDBSCAN and Gaussian mixtures

DBSCAN and HDBSCAN

  • What it does: Find clusters as dense regions separated by sparse ones and label points in sparse regions as noise.
  • How it works: DBSCAN grows clusters from points that have at least min_samples neighbours within distance eps. HDBSCAN removes the need to pick eps by exploring many density levels.
  • Use it when: Clusters have arbitrary shapes, the number of clusters is unknown, or you want outliers identified automatically (geospatial data, anomaly-aware grouping).
  • Avoid it when: Densities vary a lot between clusters (prefer HDBSCAN), or the data is very high dimensional.
  • Key settings: DBSCAN: eps and min_samples. HDBSCAN: min_cluster_size. Both are in scikit-learn (sklearn.cluster).
from sklearn.cluster import DBSCAN, HDBSCAN
labels = HDBSCAN(min_cluster_size=25).fit_predict(Xs)   # -1 means noise
print((labels == -1).mean(), "share flagged as noise")

Gaussian mixture model (GMM)

  • What it does: Models the data as a mix of bell-shaped clusters and gives each row a probability of belonging to each (soft clustering).
  • How it works: Fits means, covariances and mixing weights with the expectation-maximisation algorithm. Choose the number of components by BIC or AIC.
  • Use it when: Clusters overlap or are elliptical, or you need probabilities and a density model.
  • Avoid it when: Many features relative to rows (covariances are hard to estimate); non-Gaussian shapes.
  • Key settings: n_components, covariance_type.

4. Dimensionality reduction

Principal component analysis (PCA)

  • What it does: Rotates the data onto new axes (principal components) ordered by how much variance they capture, so you can keep the first few.
  • How it works: Uses the eigenvectors of the covariance matrix (singular value decomposition, step 02). Components are linear combinations of the original features and are uncorrelated.
  • Use it when: Compressing correlated features, removing noise, speeding up other algorithms, de-correlating inputs, or a first 2D look at the data.
  • Avoid it when: You need interpretable original features, the structure is non-linear, or features are unscaled (always standardise first).
  • Key settings: n_components (an integer, or a float such as 0.95 to keep 95% of the variance).
from sklearn.decomposition import PCA
pca = PCA(n_components=0.95).fit(Xs)
print(pca.n_components_, pca.explained_variance_ratio_.cumsum()[:10])

t-SNE and UMAP: for pictures, not for features

  • t-SNE and UMAP embed high-dimensional data into 2D or 3D so similar rows land close together. They are excellent for visualising embeddings and cluster structure.
  • Distances between far-apart clusters and cluster sizes are not reliable, and results change with settings (perplexity for t-SNE; n_neighbors and min_dist for UMAP). Use them to explore, not to prove.
  • UMAP is faster than t-SNE and keeps more global structure; it is available in the umap-learn package.
  • Autoencoders (step 12) learn a non-linear compressed representation with a neural network.

5. Anomaly detection

MethodIdeaNotes
Isolation ForestRandom splits isolate unusual points in fewer stepsFast, scales well, strong default; set contamination carefully
Local Outlier FactorCompares a point's local density to its neighbours'Finds outliers relative to local context
One-Class SVMLearns a boundary around normal dataSensitive to scaling and parameters; best on smaller data
Reconstruction errorAutoencoder or PCA that fails to rebuild unusual rowsUseful for images and sensors
from sklearn.ensemble import IsolationForest
iso = IsolationForest(n_estimators=300, contamination="auto", random_state=0).fit(Xs)
scores = -iso.score_samples(Xs)          # higher = more anomalous
flag = iso.predict(Xs) == -1

Anomaly detection usually has few or no confirmed labels. Review the top-ranked rows with experts, tune the alert threshold to the team's review capacity, and measure with precision at k once feedback exists.

Practice
  1. Segment a customer dataset with k-means for k from 2 to 8 and profile the winning clusters in plain language.
  2. Run HDBSCAN on the same data. How many customers does it call noise?
  3. Reduce to two PCA components and plot the clusters. Then try UMAP and compare.
